# changeur-de-couleur

Mini-projet de changeur de couleur aléatoire en RGB, réalisé avec HTML, CSS et JavaScript par Marc et Armel

## 🚀 À propos du projet
Ce projet est une application web interactive simple qui permet de générer de manière aléatoire des couleurs au format RGB (Rouge, Vert, Bleu) et de modifier dynamiquement la couleur d'arrière-plan de la page en un clic.

## 🛠️ Technologies utilisées
- **HTML5** : Structure de la page et des éléments interactifs (boutons).
- **CSS3** : Style, mise en page et design responsive.
- **JavaScript** : Logique de génération des nombres aléatoires pour les codes RGB et manipulation du DOM.

## ⚙️ Fonctionnalités
- Génération aléatoire de valeurs RGB (entre 0 et 255).
- Modification instantanée de la couleur de fond (`background-color`).
- Affichage dynamique du code de la couleur active.
